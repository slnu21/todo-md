# TODO.md (portable)

**TODO.md.exe** 를 실행하면 화면 오른쪽에 할 일 위젯이 붙습니다(작업 표시줄처럼 화면 한쪽을 차지). 설치가 필요 없습니다.
위젯의 × 는 트레이로 숨기기, 종료는 트레이 메뉴나 설정에서. 로그인 시 자동 실행은 설정에서 켭니다.

- Windows 10(1803+) / 11 · Microsoft Edge WebView2 런타임(Windows 11 기본 탑재)
- 데이터: `%APPDATA%\com.slnu21.todo-md\todo.json` (설정 화면에서 폴더를 열 수 있습니다)
- 인터넷·계정이 필요 없습니다. 전 과정 오프라인입니다.

---

Run **TODO.md.exe** — a to-do strip docks to the right edge of your screen (reserving it like the taskbar). No installation.
The widget's × hides it to the tray; quit from the tray menu or Settings. Turn on launch at sign-in in Settings.

- Windows 10 (1803+) / 11 · Microsoft Edge WebView2 runtime (bundled with Windows 11)
- Data: `%APPDATA%\com.slnu21.todo-md\todo.json` (open the folder from Settings)
- No internet, no account. Fully offline.
