# TODO.md (portable)

**TODO.md.exe** 를 실행하면 화면 오른쪽에 할 일 위젯이 붙습니다(작업 표시줄처럼 화면 한쪽을 차지). 설치가 필요 없습니다.
위젯의 × 를 처음 누르면 숨기기(트레이에 남음)와 종료 중에 고르고 기억합니다(설정에서 바꿈). 로그인 시 자동 실행은 설정에서 켭니다.

- Windows 10(1803+) / 11 · Microsoft Edge WebView2 런타임(Windows 11 기본 탑재)
- 데이터: `%APPDATA%\com.slnu21.todo-md\todo.json` (설정 화면에서 폴더를 열 수 있습니다)
